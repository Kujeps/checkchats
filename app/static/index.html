Добавить аккаунты

Пары 12345.session + 12345.json или .zip с ними. Можно и просто скопировать файлы в папку data\accounts — программа подхватит их сама.

Прокси

По одному на строку. Каждому аккаунту — свой прокси навсегда. Форматы: socks5://user:pass@host:port, http://host:port, host:port:user:pass.

Поисковые запросы

Аккаунты ищут публичные чаты по этим словам через поиск Telegram (каждый запрос даёт до ~10–20 чатов). Найденное попадает в очередь проверки.

Сгенерировать запросы через ИИ

Ещё один источник — «снежный ком»: ссылки и репосты из подходящих чатов автоматически добавляются в очередь (настраивается в «Настройках»).
